# Security policy

Real World Free Agent Cleanup intentionally changes athlete lifecycle state in
the loaded career. Treat any defect that could affect unrelated athletes,
corrupt saves, expose private save data, or bypass the narrow matching rules as
security-sensitive.

Report such issues privately through this repository's **Security** tab using
**Report a vulnerability**. Do not attach personal career saves publicly.

Ordinary database compatibility reports can use a public issue after private
paths and save information are removed.
